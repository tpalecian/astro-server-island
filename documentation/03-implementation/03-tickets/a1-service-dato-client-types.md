**Description:**
Implement the Dato client wrapper and base CMS-agnostic types.

**Outcome we expect:**

## 2. Context & Scope (what/where)

**Scope:** `packages/service-dato/` only

**Dependencies:** None.

**Unblocks:** A2, A3, A4

**Steps:**
